# 游戏模式 · 设计规格 v0.1

> 目标：在 wordpacer（排程器）里加一个**独立的、默认不结算的**小游戏——背单词喂肥鱼。
> 定位声明：游戏模式是**附加玩法**，不是产品的第二个核心。它**不写 review_logs、不动 fsrs_\*、不写 sessions**，
> 对排程的影响恒为零。这与 `rereview.ts` / `todayWords.ts` 已有的两个「只读」入口是同一类。
> 游戏页是**自己的一个明亮小世界**（用户明确要求照搬 dsh-whale-widget 的配色），离开即回到暗色台灯主题。

---

## 1. 玩法闭环

```
选难度 → 开局（饱食度 100）
   ↓
出题（英→中 或 中→英，四选一）
   ↓
答对 ──→ 肥鱼吃一碗饭（+20 饱食度，封顶 100）→ 下一题
答错 ──→ 没饭 → 肥鱼催一句 → 下一题（不扣血）
   ↓
饱食度随时间掉（易 12s/格 · 中 8s 格 · 难 5s/格）
   ↓
掉到 0 → 宽限期（易 12s / 中 10s / 难 8s）：屏幕底部开始被咬出缺口
   ↓
宽限期内答对 → 立刻回一口（+20），恢复
宽限期结束 → 肥鱼张嘴把整个画面吞掉 → 黑屏 → 结算 → 再来一局
```

**核心节奏**：中档下一碗饭 ≈ 12.8 秒。四选一读题通常 6–8 秒 ⇒「一直答得出来就能活，停手就会死」。

## 4. 题目生成

### 4.1 单向 vs 双向

每题掷一次硬币决定方向：

- **英→中**：题面 `headword`（衬线体大字 `.word`），4 个选项是从义项池里抽的 `meaning_cn`。
- **中→英**：题面是一个 `meaning_cn`，4 个选项是 4 个 `headword`。

一个词有多个义项时，**任取一条**作为正确答案（`senses.sort` 最小的那条优先；L2 补充义项必须过
`visibleSenses` 的可见性门槛 `src/domain/senses.ts:23-35`，否则会提前泄露用户还没「复习满 3 次」的释义）。

### 4.2 干扰项（待用户最终确认策略）

**方案 A（推荐）· 全库随机 + 防重叠过滤**
1. 从全库义项池随机抽 3 条；
2. 与正确答案做**同义检测**：中文侧按「去标点后包含关系 / 编辑距离 ≤ 1 / 共享 ≥ 2 个连续汉字」判为重复，重抽；
3. 与正确词条同 norm、同 headword 的一律丢弃；
4. 三个干扰项之间也互查，重复就重抽（最多 12 次，兜底用固定顺序补齐）。

**方案 B· ECDICT 同词性 + 同频带**（工期 +1 天，要打包几 MB 词库）
—— 调研强烈推荐，但用户原话是「错误选项在整个词库里面随机」。

难度微调（不引入外部数据的前提下）：
- 易：干扰项优先取**短释义**（字数 ≤ 正确项），一眼能扫完；
- 中：随机；
- 难：干扰项优先取**与正确项字数相近**的释义，制造视觉混淆。

### 4.3 出题顺序

池子先洗牌，依次出题；出完一轮进入循环模式：**重新洗牌但保证与上一题不同词**。
同一个词相邻两题不重复（`noRepeatWindow = 3`）。

## 5. 饥饿系统（纯函数 + 可单测）

### 5.1 状态机

```ts
type GamePhase = "idle" | "playing" | "grace" | "eating" | "over";
type Difficulty = "easy" | "normal" | "hard";
```

| 档位 | 每格秒数 | 满食续航 | 一碗饭买到的秒数 | 宽限期 |
|---|---|---|---|---|
| 易 easy | 12s | 60s | 12s | 12s |
| 中 normal | 8s | 40s | 8s | 10s |
| 难 hard | 5s | 25s | 5s | 8s |

**格 = 20 饱食度**（5 格满，`SATIETY_MAX = 100`）。掉速 = `20 / 每格秒数` 每秒。
**一碗饭（+20）= 一格 = 恰好「每格秒数」那么多秒**，所以三档的生死线就是：
易 12 秒答对一题、中 8 秒、难 5 秒。四选一读题通常 5–8 秒 ⇒ 中档贴着 break-even，
一停手就掉 —— 这正是「要不断喂」的手感来源。

### 5.2 关键规则

1. **答对 +20，封顶 100**。满了以后答对不再增加，但**不会加速掉**（用户明确要求）。
2. **答错不扣血**，只是没饭。肥鱼念一句催促台词（台词从池子里随机，**不重复质检**：同一句 3 题内不重复）。
3. **饱食度归零 → 进入 grace**，宽限期仍按原速度掉（负值钳到 0），屏幕底部出现被咬的缺口动画。
4. **宽限期内答对 → 立刻回到 20，退出 grace**。
5. **宽限期结束 → over**，播吞屏动画（≤1.2s，可点击跳过）。
6. **离开游戏页（`page !== "game"` 或窗口失焦）→ 冻结计时**。实现上把 `now` 的差值丢弃，不补算。
7. **重开永远从满格开始**，不做死亡惩罚累加。
8. 不设「新手强制第一局」之类的隐藏规则——难度由用户自己选，不想被强制。

### 5.3 时间怎么走

domain 层**不允许** `Date.now()`（`AGENTS.md` 硬约束 1）。
所有推进写成 `tick(state, elapsedMs, ...)`、`answer(state, correct, ...)` 这样的纯函数，
由 UI 侧的 `requestAnimationFrame` 循环提供 `elapsedMs`。这样整套饥饿逻辑可以在 vitest 里零时钟测试。

### 6.2 造型要点

- 描边统一 `#1B2B55`，宽度 = 画布宽 1.15%–1.3%，`linecap/linejoin: round`。
- 1.8 头身超变形 chibi：头占 5/6 画布。
- 眼睛是最强锚点：竖蛋形（w/h ≈ 0.76），单眼 ≈ 脸宽 0.55；虹膜平涂无瞳孔；两处高光（大椭圆 w65×h55 + 底部扁椭圆 w50×h16）；**一条超出眼形向右上甩出的粗眼睑线**（全身唯一表情线）。
- 腮红是**两道斜线**，不是色块。
- 鳍：三角带内凹缺口，上缘平直、下缘一条冷灰蓝反向高光带。
- 呆毛：月牙形，左起笔右抛再勾回。
- 头饰：9–11 个圆顶扇形沿弧线排布的女仆发箍。

### 6.3 动作清单（全部纯 CSS/SVG，零素材）

| 状态 | 做法 | 时长/缓动 |
|---|---|---|
| 呼吸 | `scale(1, 1.02)`，原点在脚底 | 3.6s ease-in-out infinite alternate |
| 眨眼 | 眼睑 path 的 `d` 用 CSS 变量切换 / `scaleY` 压扁 | 每 3–6s 随机 |
| 摆尾 | 尾根为 `transform-origin`，`rotate(±4deg)` | 2.4s infinite |
| 张嘴吃饭 | 嘴 path 展开 + 饭团从右下方飞入 + 咀嚼两次（`scaleY` 0.94/1.02） | 420ms，`cubic-bezier(.34,1.56,.64,1)` |
| 鼓脸颊 | 脸颊椭圆 `scale` 1 → 1.12 | 与吃饭同步 |
| 吃饱打嗝 | 身体弹一下 + 头顶冒一个气泡 | 600ms |
| 饿到发抖 | 躯体 `translateX(±1.5px)` 高频小幅 | 120ms infinite（<30% 饱食度起） |
| 被投喂开心 | 眼睛眯成弧 + 爱心飘起 | 500ms |
| 被吞屏 | 嘴部 path 放大到覆盖全屏 → 黑 | ≤1.2s，可点击跳过 |

**reduce-motion**：`styles.css` 已有全局兜底（`styles.css:163-172`），新动画一律用普通 `animation`，
不写 `!important`、不用 JS 直接改 style 做循环——保证能被媒体查询一键关掉。

### 6.4 场景

- 底部是海面（两层波浪 SVG，横向平移动画），肥鱼站在浪上。
- 上方 60% 是题面卡片区（**暗色卡面**，与 app 本体一致），形成「上面是学习、下面是游戏」的分区。
- 底部一条**饱食度条**：分 5 格，随饥饿变色（>60% `#2fa24c` → 20–60% `#e89a2e` → <20% `#e0433f` 并脉冲）。

## 7. 音效（Web Audio 现场合成，零文件）

项目里没有任何音频资源、也没有 public 目录。用 `OscillatorNode` + `GainNode` 合成：

| 事件 | 合成方式 |
|---|---|
| 答对（吃饭） | 两个正弦 880→1320Hz 短滑音 + 低频「咕」的三角波 |
| 答错 | 160Hz 方波 90ms，快速衰减 |
| 吃饱打嗝 | 220Hz 三角波 + 随机颤音 |
| 饥饿警告 | 420Hz 短促「嘀」，每秒一次 |
| 吞屏 | 噪声缓冲 + 低通扫频 800→80Hz，600ms |

- **默认静音**（用户选的），设置里一个开关。
- `AudioContext` 必须在用户手势后创建/恢复（浏览器策略），挂在第一次点击「开始」上。
- 音效开关状态存 `settings` 表，键名 `game_sound`。
