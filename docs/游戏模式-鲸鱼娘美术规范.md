## 1. 技术实现方式

**角色 = 单张 PNG 精灵图；气泡 = 运行时生成的 inline SVG；动画 = CSS transition + 少量 rAF。**

| 层 | 实现 | 证据 |
|---|---|---|
| 角色本体 | `<img class="dshwv-img">` 载入 `assets/DSniang1.png`（610×610 cut-out 透明底） | jan:1338-1349；lib:26-31 |
| 备用整图 | `DSniang02.png`（1026×1026，**气泡已画进图里**，仅旧版兼容） | lib:28-31 |
| 气泡 | 代码拼 `<svg viewBox="0 0 1026 700">`：一个 `<path>` + 两个 `<ellipse>` | jan:371-382 |
| 动画驱动 | **角色零 @keyframes**，只有 CSS `transition:transform` + JS 直接写 `style.transform` | jan:570、19707、19828 |
| 全局 keyframes | 仅 6 个，全是菜单/面板进出场，与角色无关 | jan:914/918/940/968/1007/1091 |
| rAF | 余额数字滚动、泡泡中心测量、音频排期（**均非角色位移**） | jan:19032-19063、14007 |
| 无 | 无 Lottie / Canvas / Web Animations / SVG SMIL（grep 0 命中） | — |

**没有 idle/呼吸/眨眼/说话/饿/吃东西/睡觉状态机**：`grep 眨眼|blink|呼吸|idle|feed|affinity` 在两端 JS **0 命中**；`pet.json`（affinity 72、treats 18）不被本插件读写，属另一个宠物。

## 3. 造型语言（可执行绘制指令）

画布 610×610，重心偏右，**除描边外零阴影零发光**——纯扁平 + 硬边冷白高光。

- **描边**：统一 `#1B2B55`，**不按部位变宽**。横切实测：脸颊 7px、眼睑 8px、发丝 3–6px ⇒ **约为画布宽 1.15%–1.3%（11–13‰）**，发丝内部细节 0.5%。`linecap/linejoin:round`（气泡侧同样 round，jan:379）。
- **头身比**：头（含发+头饰）约 610×600，颈下仅留约 100px ⇒ **约 1.8 头身超变形 chibi，头占 5/6 画布高**。脸盘 bbox x256–450(w195)×y339–502(h164) ⇒ **脸 0.32W×0.27H**，外廓椭圆 rx/ry 约 1.19；下颌极短，收口弧半径约为脸宽 0.18，无下巴尖。
- **眼睛（最强锚点）**：眼内区 w 约 105–110 × h 约 140 ⇒ **单眼约为脸宽 0.55、脸高 0.85，w/h 约 0.75–0.79 的竖蛋形**。三层结构：
  1. **眼睑线**——一条**超出眼形、向右上甩出的粗弧**（厚 8px），全身唯一「表情线」，把眼压成半睁的懒/嫌弃眼神；
  2. **虹膜**＝眼形全部内区，纯 `#6B83BD` 平涂，**无瞳孔、无下眼白**；
  3. **两处高光**：左上大椭圆 w65×h55（约为眼宽 0.59，略溢出眼廓）+ 底部扁椭圆 w50×h16（w/h 约 3.1）。
  眉毛：4–6px 短斜线，`#7A738B` 偏紫灰，压刘海、略高于眼睑线。
- **腮红**：**不是色块，是两道短斜线「‖」**。`#D6BBC0`，长约为脸宽 0.09，间距约为脸宽 0.04，与水平夹角约 75°。
- **鳍（鲸鱼特征）**：三角形带内凹缺口，bbox x49–199(w151)×y300–479(h180)，自耳位向左下伸出，**长宽比 0.84**。上缘 `#4D588D` 平直面，自根部 45° 斜下；下缘 `#BCC8E4` 冷灰蓝**反向高光带**（厚约 12px），**中段做一个内凹弧缺口**形成须状分叉。右侧另有耳鳍（`#8FA8D2`，半透明感）藏于头饰后。**尾巴不在任何素材里（cut-out 只到颈下）**。
- **呆毛**：`#556396` 到 `#626FA3` 的**月牙**，bbox x238–420(w183)×y16–129(h114)，**左端起笔、右上抛、再向右下勾回**，最粗 22px 收尖至 3px，根部与头饰第 6 瓣重叠。
- **头饰**：女仆荷叶边发箍 = **9–11 个半径约 34px 的圆顶扇形**沿 y 约 120 的弧线排布、外描边同 ink，每瓣内一条 `#C4C2CD` 细阴影弧（右倾 15°），整体左低右高。
- **配饰**：领口 `#3E477B` 五瓣蝴蝶结（圆角三角瓣）+ 中心**菱形宝石**（`#66A4DA` 底 + `#DBEBFF` 左上三角高光 + 外圈 3px 白描边）；侧发小蝴蝶结 `#72A8CC`。
- **整体**：扁平，零渐变零内发光；**唯一质感手段是分色硬边阴影**；高光一律冷白偏蓝，绝不暖白。

## 4. 状态与动作清单（真实存在的全部）

角色侧**只有 3 段动作**，全建立在 `.dshwv-body` 的 transition 上：

| # | 状态 | 触发 | transform | 时长 / 缓动 | 证据 |
|---|---|---|---|---|---|
| 1 | 按下挤压 | pointerdown 落在不透明像素 | `scaleY(0.88) scaleX(1.05)`，原点 `50% 100%`（**脚底为轴**） | `.22s`，`cubic-bezier(.34,1.56,.64,1)`（**带过冲的弹性**） | jan:19707、570、19828 |
| 2 | 松手回弹 | pointerup | `scaleY(1) scaleX(1)` | 同上；按压 < 32ms(`PRESS_VISUAL_TAP_MS`) 时先 `transition:none` 强制提交一帧再恢复 | jan:19836-19844 |
| 3 | 镜像翻转 | 贴左吸附 | 根 `scaleX(-1)`，文字/动图内层再 `scaleX(-1)` 抵消 | `.3s ease` / 内层 `.16s` | jan:568、627、617 |

**气泡开合（最值得复刻的多段动画）**：三件套按**逆序 0.13s 步进**缩放淡入：
```css
.dshwv-pop .dshwv-bshape,.b1,.b2{opacity:0;transform:scale(.7);
  transform-box:fill-box;transform-origin:50% 50%;
  transition:opacity .2s ease,transform .2s ease}
.dshwv-pop-open .dshwv-bshape{transition-delay:.26s} /* 大圈最晚 */
.dshwv-pop-open .dshwv-b1{transition-delay:.13s}
.dshwv-pop-open .dshwv-b2{transition-delay:0s}      /* 小圈最先 */
/* 关闭时反转：bshape .1s -> b1 .2s -> b2 .3s */
```
证据 jan:614-624；文字再晚 0.36s 淡入（`opacity .16s ease .36s`，jan:625-626）。
其他：余额滚动 = rAF + easeOutCubic（`1-Math.pow(1-t,3)`），`ANIM_MS=700`（jan:19032-19063）；行跑马灯每行随机 1500–4500ms（jan:17986）；菜单 `MenuIn .16s ease-out`/`Out .14s ease-in`（jan:914、918）。

- 主体包络 x81–827、y15–479（746×464），两条弧拼成、左下挖出喷口，路径原文（jan:371）：
  `M 827 248 A 373 232 0 1 0 81 246 A 373 232 0 0 0 301 465 A 57 32 10 0 0 413 484 A 373 232 0 0 0 827 248 Z`
- 描边 `#203170` + `stroke-width="18"`（**约为画布宽 1.75%，比角色描边粗 1.3–1.5 倍**），`linejoin/linecap:round`，填充 `#FFFFFF`（jan:379）。

**文字排版**（jan:625-652）：
- 容器 `left:var(--dshw-vx,44.25%);top:var(--dshw-vy,36%);width:66%;height:64%;translate(-50%,-50%)`，flex 列居中——锚点是 **SVG 主体包围盒的视觉中心**（44.25%/36%），非几何中心（jan:13977）。
- 色 `#536ba9`；行高 1.15；默认 `white-space:nowrap`（仅自定义安全框才 normal，jan:640-644）。
- 字号 `calc(var(--dshw-u) * N)`，`--dshw-u = 挂件基础尺寸/1026`（jan:588）；N 由档位 1–50 线性映射 40 到 240（jan:17424-17428）。
- 三档预设：`.dshwv-label` 66/600 + `letter-spacing .06em`；`.dshwv-amount` 128/**800**/lh1.05；`.dshwv-period` 104/800；`.dshwv-hint` 56/`#9fb0d9`（jan:648-652）。
- 行文字 `text-shadow:0 1px 2px rgba(255,255,255,.6)`（jan:1090）；带底色块时关掉并给 `padding:1px 6px;border-radius:7px`（jan:18354-18356）。字体可逐行指定 `fontFamily`（jan:18373-18375）；倒计时强制 `tabular-nums`（jan:18377）。

## 7. 可复用度（React + CSS）

**可直接搬**
1. 全部 17 个 hex（§2.1/2.2）→ `:root` 变量。
2. 气泡 SVG 三条几何（viewBox + path d + 两枚 ellipse，jan:371-382），纯静态、原样复制。
3. 气泡开合：`scale(.7)+opacity` + 0.13s 逆序 delay（§4）。
4. 按下挤压 `scaleY(.88) scaleX(1.05)` + `cubic-bezier(.34,1.56,.64,1)` + `origin:50% 100%`。
5. 14 套跑马灯渐变 + `background-clip:text` + 2.6s linear infinite。
6. 文字锚点 44.25%/36% 与 `u = 容器宽/1026` 的等比 calc 体系。
7. 镜像翻转（外层翻 + 内层抵消）。

**必须重画**
- 角色本体是 **AI 生成位图**，且**资产明确不在 MIT 覆盖内**（PROV:11、PROV:19-21、README:500）——呆毛月牙、鳍+缺口、三层眼、九瓣发箍、菱形宝石都需按 §3 重绘。
- **无尾巴、无睡觉/吃/说话帧**：要这些状态必须自建状态机 + 新素材，本插件无参照。

**风险**
1. 音效等 `assets/**` 全部 as-is 不可再分发（PROV:11），只能自产。
2. `transform-box:fill-box` 是气泡缩放前提（jan:614）；别把 transform 写进 SVG path 的表现属性（会被 CSS 覆盖，插件踩过，jan:498-500）。
3. 点击依赖 `svg *{pointer-events:visiblePainted}`（jan:608-613），若用 `<img>` 做气泡会丢掉不规则命中区。
4. 锚点靠 `getBBox()` 运行时测量（jan:13979-13984），SSR 首帧会先用兜底值，可能跳一下。
5. 行级字号/字体/颜色是数据驱动的（`bubbleModuleFontU` 1–50 映射 40–240u），React 里建议内联 `--row-fs` 变量而非 N 个 class。
