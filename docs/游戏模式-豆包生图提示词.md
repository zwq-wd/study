# 游戏模式 · 肥鱼形象生成提示词（豆包）

> 目标：给「喂肥鱼」小游戏生一套鲸鱼娘立绘。
> 参考对象是用户自己的插件 `dsh-whale-widget` 里的角色（`assets/DSniang1.png`）。
> **那张 PNG 不在该插件的 MIT 许可范围内**（`PROVENANCE.md:11`），所以只能照着造型语言重新生成，不能直接搬运。
> 色值与比例来自 `docs/游戏模式-鲸鱼娘美术规范.md`（对原 PNG 逐分区中位数采样）。

## 核心经验

**不要指望一张图出八个表情。** AI 生成表情网格时，每一格的发饰瓣数、眼睛大小、描边粗细都会漂移，
最后八张图拼在一起会明显不像同一个人。

正确流程：

1. **先定一张「基准图」**，挑最满意的那张存下来；
2. 之后**每一张状态图都把基准图作为参考图（垫图）上传**，提示词开头固定写「保持形象不变，只改表情」。

## 一、基准图（只做一次）

```
原创角色设计，Q 版超变形 chibi 风格，约 1.8 头身，头部占画面约六分之五，身体小巧。
一个拟人化的小鲸鱼女孩，正面站立，从头到脚完整入镜，神态平静。

头发是蓝紫色（#596FAE），发量很大、外轮廓就是头的形状，中分刘海压得较低，
两侧各垂一缕长发盖住脸颊边缘；发顶有一条月牙形的呆毛向左上方翘起。
戴白色荷叶边女仆发箍，发箍由约九个圆顶花瓣沿弧线排开，整体左低右高。

皮肤是暖粉白（#FEEDE6）。眼睛是全身最抢眼的部分：竖蛋形，单眼宽度约为脸宽的一半，
占脸高的四分之三；虹膜是平涂的蓝紫色（#7F96CC），没有瞳孔；眼内有两处冷白色高光，
一处是左上方的大椭圆，另一处是底部一条扁椭圆；眼睑线是一条超出眼形、向右上方甩出的粗弧线，
因此眼神看起来有点懒。

腮红不是色块，是两道灰色的短斜线，左右各一道。鼻子只是一个点。嘴唇一条小弧线。

耳朵的位置是三角形的鱼鳍，带内凹缺口，上缘深蓝灰、下缘一条冷灰蓝的反光带。身后有一条鲸鱼尾巴。
脖子下面露出一点藏蓝色的水手领，领口有一个五瓣蝴蝶结和一粒菱形宝石。

整体扁平插画风，无渐变无发光，所有轮廓统一用深藏青（#1B2B55）的圆头描边，
描边宽度约为画面宽度的 1.2%。纯白背景，角色居中，留白均匀。画面尺寸 1:1。
```

## 二、八张状态图

每张都上传基准图作为参考图，并且**开头固定加这段**：

```
以参考图中的角色为准，保持她的发型、发箍、眼睛、配色、比例、描边粗细完全不变，
只改变表情和动作。纯白背景，角色居中，构图与参考图完全一致，同样的取景范围和大小。
```

然后接对应状态：

### ① idle · 平时（默认状态）
```
安静的站姿，眼睛正常睁开，嘴角一条很小的弧线。身体自然放松。
```

### ② happy · 开心（答对）
```
双眼眯成向下弯的弧，眼睛下沿被压平，脸颊两道斜线腮红变明显，嘴角向上弯成笑脸，
头顶冒出一颗小爱心。身体微微上浮。
```

### ③ eating · 吃饭（最重要的一张）
```
嘴巴张成长圆形，露出一点口腔的暖粉色，眼睛睁大，脸颊明显鼓起，
双手（鳍）捧着一个小白碗举到嘴边，碗里冒出几粒白米饭。眼睛向下看着碗。
```

### ④ hungry · 饿了
```
上眼睑明显下压，眼神下垂显得没精神，嘴巴微张成一条小缝，脸颊瘪下去，
两侧的鱼鳍无力地垂下。头顶有一颗汗珠。
```

### ⑤ tremble · 饿到发抖（饱食度 < 30）
```
眼睛睁大、瞳孔高光变小，嘴巴张成一个小的方形，嘴角向下，露出难过的表情。
身体有轻微倾斜，脸颊上挂着两滴汗。
```

### ⑥ burp · 吃饱打嗝
```
眼睛满足地闭成弯月，嘴边有一个小小的打嗝气泡往上飘，
脸颊鼓得像含着一口气，一只手（鳍）轻轻拍着自己的胸口。
```

### ⑦ over · 结束
```
双眼闭成两条向下的线，嘴角向下弯成难过的弧线，整个人耷拉下来，
呆毛垂向一侧，腮红淡到几乎没有，身体微微下沉。
```

### ⑧ swallow · 吞屏（会被放大铺满屏幕）
```
极近景特写，只有她那颗大脑袋，嘴巴夸张地张开到整个画面宽度的三分之二，
嘴内是一片深色，上排两颗小尖牙。眼睛睁圆，身体前倾，强烈的压迫感。
```

## 三、技术规格

| 项 | 要求 | 原因 |
|---|---|---|
| 尺寸 | 1:1，1024×1024 或更大 | 缩小无损，放大发虚 |
| 背景 | **纯白**（不要透明、不要场景、不要渐变） | 抠图用；豆包给不了真透明，抠图我来做 |
| 构图 | 八张的**取景范围、人物大小、脚底位置必须一致** | 这样才能直接叠着换表情 |
| 描边 | 每个状态都要有 | 抠图后边缘才不会发虚 |
| 不要 | 阴影、投影、发光、文字、水印、边框、横排网格 | 会影响抠图和叠加 |

## 四、交付

八个 PNG，命名 `01-idle.png` … `08-swallow.png`，放到 `D:\wp\wordpacer\art\`。

拿到后在本项目里要做的事：

1. 抠成透明背景、按基准图统一裁剪对齐（统一到一个固定的画布尺寸与人物包围盒）；
2. 替换掉 `src/ui/game/Whale.tsx` 里现有的 SVG 版本；
   呼吸、摆尾、眨眼这些动效继续用 CSS 叠在图片上（`whale.css` 的 `data-mood` 选择器不用改）；
3. 因为图片比 SVG 大，需要确认打包体积与首屏加载（`src-tauri/tauri.conf.json` 目前没有 asset 协议，图片走 `import` 由 Vite 打进 bundle）。
